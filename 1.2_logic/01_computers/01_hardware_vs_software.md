# Part 1 – Hardware vs Software

## Explain Hardware
Write **at least 50 words** explaining what hardware is.
Hardware is physical parts of a computer that you can see and touch. Examples include the keyboard, mouse, monitor, processor, motherboard and hard drive. Hardware allows a computer to work and perform different tasks. Without hardware, software would not have a device to run on.

## Explain Software
Write **at least 50 words** explaining what software is.
Software is programs and applications that run on a computer. Unlike hardware, software cannot be physically touched. Examples include Microsoft Word, Google Chrome, Windows and computer games. Software tells the computer what to do and helps users complete tasks, such as writing documents, browsing websites and sending emails.

## How Do Hardware and Software Interact?
Write **at least 50 words** describing how they interact
Hardware and software work together to make a computer function. Hardware is the physical parts of a computer, while software gives the hardware instructions on what to do. For example, when you type on a keyboard, the software processes your input and displays the words on the monitor.
