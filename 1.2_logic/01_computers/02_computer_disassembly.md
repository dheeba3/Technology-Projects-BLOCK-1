## Internal Layout
Open the computer case and observe the internal components.
Describe what you see.
When I opened the computer case is opened, several important internal components such as
1.Motherboard: The main circuit board that connects all the computer components.
2.CPU (Central Processing Unit): The processor that performs calculations and executes instructions.
3.RAM (Random Access Memory): Temporary memory used to store data while programs are running.
4.Hard Drive / SSD: Stores the operating system, software, and files.
5.Power Supply Unit (PSU): Supplies electrical power to all internal components.
6.Cooling Fan: Helps prevent the computer from overheating.
7.Graphics Card (GPU): Processes images, videos, and graphics.
